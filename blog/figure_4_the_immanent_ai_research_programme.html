1. Vary a relation

    In a model collective, vary which neighbours each unit responds to. Record what the collective does after a disturbance.

  2. Predict an unfamiliar case

    Train a model on those trials. Before running a new arrangement, predict whether the disturbance will fade, spread, or split the group.

  3. Test the prediction

    Run the proposed intervention and compare the forecast with how the collective actually develops.

  4. Revise the account

    Use any mismatch to reconsider which relationships matter. Design a trial where the competing explanations predict different outcomes.

Use the result to choose the next intervention.

The backbone thesis

Software gets easier to build. Trust gets harder to earn.

As AI accelerates feature development, the enduring advantage is a dependable network: safe data models, recovery, permissions, integrations, and tools that work together. mWater connects field collection to assets, dashboards, workflows, billing, accounting, and external systems so each capability strengthens the rest.

Flagship work

Three systems changing how WASH work gets done

01
AI access and integration

Making every practitioner a potential superuser

The mWater MCP server gives AI assistants permission-aware access to documentation and data, with human approval for proposed changes. The AI-powered Integrator connects external systems from plain-language instructions.

Read the AI strategy →
02
Operational professionalization

Turning informal processes into accountable workflows

Organizations have created nearly 10,000 workflow instances across about 170 workflow types. Roughly a quarter of deployed, named types address repair and maintenance; others cover connections, procurement, installations, quality monitoring, and public health.

Read nine months of Workflows →
03
Open sector standards

A shared language for sanitation infrastructure

The Sanitation Asset Standard covers sewered and on-site systems with 27 asset types and 211 attributes. Openly licensed and platform-independent, it helps data move between organizations, tools, and institutions.

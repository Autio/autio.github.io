## 🚀 Käyttöönotto

### Vaatimukset

- Webhosting (esim. GitHub Pages, Netlify, tai perinteinen webhotelli)
- Ei erityisiä riippuvuuksia - pelkkää HTML, CSS ja JavaScript

### Asennus

1. Lataa kaikki tiedostot samaan kansioon
2. Avaa `index.html` selaimessa paikallisesti tai
3. Lataa tiedostot webhotelliisi

### Muokkaaminen

**Yhteystiedot:**
- Muokkaa `index.html` tiedostossa puhelinnumerot ja sähköpostiosoitteet
- Päivitä osoitetiedot

**Värit ja tyylit:**
- Avaa `styles.css`
- Muokkaa CSS-muuttujia `:root` osiossa:
  ```css
  --primary: #2c3e50;
  --accent: #c9a961;
  ```

**Sisältö:**
- Kaikki tekstit ovat suoraan `index.html` tiedostossa
- Muokkaa palvelukuvauksia, hintoja ja muuta sisältöä tarpeen mukaan

## 📱 Responsiivisuus

Sivusto on täysin responsiivinen ja toimii kaikilla näyttöko'oilla:

- **Desktop** (1200px+) - Täysi layout, kaikki ominaisuudet
- **Tablet** (768px-1199px) - Mukautettu layout
- **Mobile** (< 768px) - Mobiilioptimoitu hamburger-menu

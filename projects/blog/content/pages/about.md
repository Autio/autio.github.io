# About

## About the Site

This website is built with a custom static site generator designed to capture the essence of [gwern.net](https://gwern.net/) while providing easy content management and theme customization.

### Philosophy

The design prioritizes:

- **Content over chrome**: Focus on the writing, not the interface
- **Academic aesthetics**: Clean typography inspired by scholarly publications
- **Long-form reading**: Optimized for essays and research articles
- **Accessibility**: Semantic HTML, keyboard navigation, screen reader support
- **Performance**: Static HTML with minimal JavaScript

### Features

- Dark mode with system preference detection
- Reader mode for distraction-free reading
- Full-text search
- Responsive design for all devices
- Markdown-based content management
- Fully configurable color themes
- Category and tag organization
